# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。  
1. 预处理是将源代码中带有`#`的指令（如`#include`、`#define`和条件编译）进行处理，将头文件（`.h`文件）中的代码搬运到源文件中，将宏定义替换成实际的内容，并删掉源文件中的注释，结果是生成一个后缀为`.i`的纯文本文件。
2. 编译是将`.i`文件翻译为汇编语言，编译前编译器会先检查代码是否有语法、类型和声明错误，结果是生成一个后缀为`.s`的含有汇编代码的文件。
3. 编译时将汇编代码翻译成计算机能直接执行的二进制机器码，生成一个后缀为`.o`的二进制文件。
4. 链接是将程序中使用的外部标准函数的代码与`.o`文件链接，分配内存地址，生成最终的可执行文件（在Linux下通常没有后缀）。
